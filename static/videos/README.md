Place gym-themed MP4 videos here to enable the live previews used on the homepage.

Expected filenames (used by templates):
- gym_background.mp4  (main background video)
- gym_cardio.mp4      (cardio zone preview)
- gym_weights.mp4     (weights/strength preview)
- gym_yoga.mp4        (yoga/recovery preview)
- gym_studio.mp4      (studio/class preview)

Tips:
- Use H.264 MP4 for best browser compatibility. Provide a `webm` fallback if needed.
- Keep files optimized for web (small bitrate; 720p recommended).
- To replace the background with a remote URL, edit `templates/base.html` and change the `source` element.
